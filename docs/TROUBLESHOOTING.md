> 프로젝트 고유 이슈와 해결법. 공통 이슈는 workspace/.claude/docs/TROUBLESHOOTING.md 참조.

---
## 번들 사이즈 초과
**증상**: 빌드 후 번들 사이즈가 500KB 이상으로 커짐
**원인**: html2canvas 등 대용량 라이브러리가 메인 번들에 포함
**해결**: html2canvas를 동적 import(`import()`)으로 변경하여 필요 시점에만 로드. 603KB -> 378KB로 최적화 완료.

---
## html2canvas 공유 이미지 생성 실패
**증상**: 결과 페이지에서 공유 이미지 생성 시 빈 이미지 또는 에러 발생
**원인**: html2canvas가 CORS 이미지나 특정 CSS 속성을 렌더링하지 못함
**해결**: 공유 이미지용 별도 컴포넌트에서 외부 이미지 사용 제한, 인라인 스타일 사용 권장.

---
## 미추적 스크린샷 파일 (30+)
**증상**: `git status`에 30개 이상의 PNG 파일이 untracked로 표시
**원인**: E2E 테스트 또는 개발 중 생성된 스크린샷이 .gitignore에 미등록
**해결**: (미해결) .gitignore에 스크린샷 패턴 추가 또는 별도 디렉토리로 관리 필요.

---
## Toss SDK 관련 빌드 에러
**증상**: Toss SDK 관련 모듈을 찾을 수 없다는 에러
**원인**: Toss SDK 제거 후 참조 코드가 남아있는 경우
**해결**: Toss SDK 완전 제거 완료. 관련 import/참조 코드 모두 삭제됨.
