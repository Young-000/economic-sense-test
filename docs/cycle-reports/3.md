## Key Findings

### Share Image Design Principles
- "Thumb-stop test" — 상위 30%가 시선을 끌어야 함
- 외부 보는 사람에게 의미 없는 stat bars 제거 → 핵심 정보(티어, 수익률)에 집중
- html2canvas 제약: backdrop-filter 불가, box-shadow/gradient OK, 시스템 폰트 스택 사용

### Responsive CSS Strategy
- `clamp()`로 유동적 값 → @media 브레이크포인트로 보완하는 하이브리드 전략
- 모바일 퍼스트: 기존 CSS가 베이스라인, 위로 확장
- 375px 오버플로우가 가장 위험한 구간 — `calc(100% - padding)`, `word-break`, `flex-wrap` 조합으로 해결
- CSS-only 변경이라 런타임 비용 0, 리그레션 위험 최소

- share-image-redesign: 공유 이미지 전용 (ShareImageCard만 변경), 메인 UI 영향 없음
