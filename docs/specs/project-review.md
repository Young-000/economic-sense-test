## 3. UI/UX 현황 분석

### 3.1 IntroPage — 첫인상의 문제

**현재 구조 (위에서 아래):**
1. 시즌/이벤트 배너
2. 친구 도전 배너 (조건부)
3. 소셜 증거 배너 (참여자 수, 오늘 1위, 실시간 메시지)
4. "MZ 필수 테스트" 배지
5. 제목: "돈 감각 테스트"
6. 부제목
7. 모드 선택 (일반/극한)
8. 시작 버튼
9. 훅 문구 ("금손? 흙손?")
10. 특징 3개
11. 면책 고지
12. AdSense 배너

**문제점:**
- **정보 과부하**: 사용자가 CTA(시작 버튼)에 도달하기 전에 7개 섹션을 지나야 함
- **시각적 위계 부족**: 모든 요소가 비슷한 크기/강조로 경쟁
- **CTA 매몰**: 시작 버튼이 화면 중간에 위치하여 스크롤 없이 보이지 않을 수 있음 (특히 모바일)
- **소셜 증거 과다**: 실시간 메시지가 하드코딩된 가짜 데이터 (`방금 누군가 "금손 전략가" 획득!`)로 신뢰도 저하
- **시즌 배너 공간 낭비**: 특별 이벤트가 아닌 기간에도 항상 표시되어 공간 차지

### 3.2 GamePage — 비교적 양호

**잘 된 점:**
- 진행률 표시 (라운드 + 프로그레스 바)
- 잔액 실시간 표시
- 결과 오버레이 애니메이션
- 1등 기록 비교 차트

**개선 여지:**
- 선택지 카드 간 비교가 직관적이지 않음
- 확률 바 크기가 작아 한눈에 비교 어려움

### 3.3 ResultPage — 과도한 복잡성

**현재 구조 (위에서 아래):**
1. 컨페티 효과 / 업적 팝업
2. 신기록 배지
3. 티어 배지 (히어로)
4. 투자자 유형 카드
5. 최종 자산 카드
6. 친구 도전 비교 (조건부)
7. 바이럴 CTA 섹션 (상위 N%, 도전장, 이미지 공유)
8. 랭킹 등록 (닉네임 입력 + 제출)
9. TOP 10 랭킹 (토글)
10. 자산 변화 그래프
11. 투자자 유형 상세 설명
12. 투자 성향 분석 (공격성/합리성/운 바)
13. 업적 섹션 (토글)
14. 액션 버튼 (이미지 공유, 텍스트 공유, 다시 도전)
15. AdSense 배너
16. 공유 이미지 카드 (오프스크린)
17. 공유 모달 (조건부)

**문제점:**
- **902줄 단일 컴포넌트**: 글로벌 컨벤션 150줄 기준의 6배
- **16개 상태 변수**: useState가 과도하게 사용됨
- **12개 이벤트 핸들러**: 공유 로직만 6개
- **정보 과다**: 사용자가 핵심 결과(티어 + 수익률)를 파악한 후 관심을 잃을 가능성 높음

### 3.4 스타일링

**global.css (3,198줄):**
- 모든 페이지 + 컴포넌트 스타일이 단일 파일에 혼재
- CSS 변수 활용은 좋으나, 클래스명이 체계적이지 않음 (BEM도 아니고, 유틸리티도 아닌 혼합)
- 애니메이션 keyframes가 11개 이상 정의되어 있으며 일부 중복 (`bounce`, `pulse` 등)
- 다크 테마만 지원 (라이트 모드 없음)
- Tailwind 마이그레이션 예정이나 아직 미착수

- 다만 Feature 1이 먼저 완료되어 깨끗한 git status에서 Feature 2 작업하는 것이 이상적
