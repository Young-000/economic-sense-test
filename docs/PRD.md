# Economic Sense Test - PRD
> v1.0 | 최초 작성: 2026-02-13

## 프로젝트 목적
경제 상식을 퀴즈 형태로 테스트하여, 사용자가 자신의 경제 지식 수준을 확인하고 공유할 수 있는 게임형 웹앱을 제공한다. 바이럴 공유를 통해 자연적인 사용자 유입을 유도한다.

## 타겟 사용자
- 경제/금융에 관심 있는 20-40대
- SNS 공유를 즐기는 사용자
- 짧은 시간(3-5분) 내에 재미있는 콘텐츠를 소비하려는 사용자

## 핵심 기능
1. **경제 상식 퀴즈**: 카테고리별 경제 문제 출제 및 풀이
2. **티어 시스템**: 점수 기반 등급 부여 (경제 초보 ~ 경제 박사 등)
3. **랭킹 시스템**: 전체 사용자 대비 순위 확인
4. **바이럴 공유**: html2canvas를 활용한 결과 이미지 생성 및 SNS 공유
5. **시즌 시스템**: 주기적으로 새로운 문제 세트 제공

## 비기능 요구사항
- 번들 사이즈 400KB 이하 (현재 378KB gzip 달성)
- 첫 화면 로딩 2초 이내
- html2canvas 동적 import으로 초기 로딩 최적화
- 모바일 반응형 (토스 미니앱 대응)

## 기술 스택
- Frontend: React 18 + TypeScript + Vite 7.3
- DB/Auth: Supabase (economic_sense_test 스키마)
- 이미지 생성: html2canvas (dynamic import)
- 라우팅: react-router-dom
- 테스트: Vitest (단위) + Playwright (E2E)
- 배포: Vercel

## 데이터 모델
- `questions`: 문제 데이터 (질문, 보기, 정답, 카테고리, 난이도)
- `categories`: 문제 카테고리 (경제, 금융, 투자 등)
- `user_scores`: 사용자 점수/랭킹 기록
